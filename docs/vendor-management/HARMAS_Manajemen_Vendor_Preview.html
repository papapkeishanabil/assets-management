Dampak pada Menu Vendor Aktif
Saat status Kelayakan = Disetujui, data masih berada pada Manajemen Vendor. Ketika kerja sama resmi dimulai dan Status Kerja Sama = Aktif, aplikasi menghubungkan data itu ke Master Data → Vendor Aktif, tanpa membuat data vendor duplikat.

Seluruh data mulai dari prospek, follow-up, perubahan koordinat, foto lokasi, sampel, skor QC, pengambil keputusan, hingga riwayat pekerjaan harus tetap dapat diaudit.
